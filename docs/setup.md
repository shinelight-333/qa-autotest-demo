# Подготовка окружения

## Локальный стенд

Объект тестирования — учебный демо-магазин «Поход». Его разворачивали локально;
исходники и дистрибутив сайта в этот репозиторий не включены.
Тесты рассчитаны на его конкретное API, DOM и данные `hike-demo-v1`.
Произвольный другой магазин или одна смена URL не заменяют этот стенд.

До запуска нужен работающий сайт с базовым API-путём `/api/v1/` и
учебными товарами/промокодами ниже. В `HIKE_BASE_URL` указывают корень сайта, без `/api/v1`.
Порт `18080` — пример и значение по умолчанию тестов; порт существующего стенда может отличаться.

Поддерживаются только HTTP-адреса `localhost` и `127.0.0.1`. Удалённый сайт, HTTPS,
Selenium Grid и реальные платежи не входят в этот набор.
Автотесты сами не запускают приложение, Docker или сброс БД и не переключают дефекты.

## Python и зависимости

Нужны Python **3.12** и [uv](https://docs.astral.sh/uv/getting-started/installation/).
Из корня репозитория:

```powershell
uv sync --locked
```

Команда создаёт локальную `.venv` и устанавливает версии из `uv.lock`.
При первоначальной установке нужен доступ к реестру пакетов.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `HIKE_BASE_URL` | `http://127.0.0.1:18080` | Корень локального сайта |
| `HIKE_TIMEOUT` | `15` | Таймаут HTTP, WebDriver и ожиданий; больше 0 и не больше 120 секунд |
| `HIKE_BROWSER` | `chrome` | `chrome` или `edge` |
| `HIKE_DRIVER_PATH` | поиск в PATH | Путь к локальному `chromedriver` или `msedgedriver` |
| `HIKE_BROWSER_BINARY` | выбор драйвера | Путь к браузеру при нестандартной установке |
| `HIKE_HEADED` | `0` | `1` — видимое окно; иначе headless |
| `HIKE_HIDDEN_PRODUCT_ID` | не задан | Настоящий ID архивного `CAMP-HIDDEN`; нужен API-04 |

Настройка PowerShell, действующая для текущего окна:

```powershell
$env:HIKE_BASE_URL = 'http://127.0.0.1:18080'
$env:HIKE_BROWSER = 'chrome'
$env:HIKE_DRIVER_PATH = 'C:\Tools\chromedriver.exe'
# Замените значением из локальной БД, как описано ниже:
$env:HIKE_HIDDEN_PRODUCT_ID = '<ID CAMP-HIDDEN>'
```

Значение `<ID CAMP-HIDDEN>` — обозначение для замены, не готовый ID.
`.env` автоматически не читается. Пароли существующих покупателей не нужны:
фикстуры создают свои учётные записи с уникальными email и случайными паролями.

## Браузер и WebDriver

Для UI установите Chrome или Edge и подходящий по версии драйвер из официального источника:
[ChromeDriver](https://developer.chrome.com/docs/chromedriver/downloads)
или [Microsoft Edge WebDriver](https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/).
Задайте `HIKE_DRIVER_PATH` либо добавьте драйвер в PATH.
Автоматической загрузки драйвера в коде нет.

Создаётся временный профиль браузера. Для каждого теста используется отдельный WebDriver,
который закрывается при завершении фикстуры. Проверка ширины 375 px использует эмуляцию
viewport через CDP в Chrome/Edge, а не физический телефон.

## Требования к учебным данным

| Данные | Требование | Сценарии |
|---|---|---|
| Каталог `hike-demo-v1` | Не больше 50 активных товаров; для пагинации нужны минимум 24, для UI-05 — больше 24 | Подготовка каталога, API-10, API-16, UI-05 |
| Категории | Одна категория с 1–12 товарами и одна с более чем 12 товарами | UI-05, UI-15 |
| `CAMP-MUG` | Цена `199.90`, достаточный остаток; для отдельных сценариев минимум 2 | Корзина, заказы, UI-07/08/10/11 |
| `CAMP-PROMO` | Цена `3000.00`, достаточный остаток; для API-13 минимум 2 | API-03, API-12, API-13 |
| `CAMP-BULK` | Остаток не меньше 100 | API-05 |
| `CAMP-LAST` | Остаток ровно 1 в начале сценария | API-14 |
| `CAMP-HIDDEN` | Существующий неактивный товар с положительным остатком | API-04 |
| `CAMP-ZERO` | Остаток 0 | UI-16 |
| `CAMP-LONG` | Товар с длинным названием из демо-набора | UI-13 |
| `CAMP-PRICE-99`, `CAMP-PRICE-120`, `CAMP-PRICE-1000` | Товары с соответствующими числовыми ценами; `CAMP-PRICE-120` доступен к покупке | API-16, smoke, UI-11 |
| `HIKE10` | Действующий промокод на 10%; в демо-наборе действует год от заполнения | API-13 |
| `OLD10` | Истёкший промокод | API-12 |

Для API-04 ID получает владелец локального стенда через read-only запрос:

```sql
SELECT id, sku, is_active, stock
FROM catalog_product
WHERE sku = 'CAMP-HIDDEN';
```

По публичному API архивный товар недоступен; ID нельзя подставлять наугад.
Ответ `404` для несуществующего товара не доказывает обработку архивного товара.

## Данные после запуска

Запускайте проверки последовательно одним процессом, без `xdist` и без параллельных
покупок на том же стенде. Корзины и аккаунты изолированы по пользователю, остатки общие.
Оплаченные заказы расходуют товар; пользователи, адреса, отзывы и история остаются в БД.

API-14 с включённым учебным дефектом оставляет `CAMP-LAST` с остатком 0. Его повторный запуск
без подготовки данных проверит предусловие и упадёт раньше целевого действия.
Переключение дефектов не восстанавливает ранее испорченные данные.
Подготовкой чистого учебного набора управляет владелец стенда отдельно от тестов.

## Если запуск не удался

| Симптом | Что проверить |
|---|---|
| `ConnectionError` / отказ соединения | Сайт уже запущен, порт правильный, URL без `/api/v1` |
| Ошибка `HIKE_BASE_URL` | Адрес HTTP, хост `localhost` или `127.0.0.1`, без логина, пути и query |
| Не найден драйвер | Реальный путь `HIKE_DRIVER_PATH`, наличие файла или драйвера в PATH |
| `SessionNotCreatedException` | Совместимость установленного браузера и WebDriver |
| Ошибка предусловия API-04 | Корректный ID существующего неактивного `CAMP-HIDDEN` |
| Ошибка предусловия API-14 | В начале запуска нужен остаток 1, а не 0 после предыдущего прогона |
| Ошибка другого предусловия по остаткам | Данные уже расходовали; подготовьте учебный набор перед повторением |
| Ошибка сессии или CSRF | Один адрес сайта для запуска, корректный origin и настройки локального приложения |
| `teardown error` | Не удалось очистить корзину/отменить новый заказ; изучите отдельно от основной проверки |

При разборе падения отделяйте дефект приложения от неверных предусловий и ошибок инфраструктуры.
