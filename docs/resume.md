# Описание проекта для резюме

Ниже формулировка под фактическое содержимое репозитория. Вместо обозначения ссылки
нужно вставить прямой адрес опубликованного `qa-autotest-demo`.

---

**Учебный проект: тестирование и автоматизация демо-магазина**  
GitHub: **[прямая ссылка на ваш репозиторий]**

- На основе требований локального демо-сайта подготовил карту покрытия и чек-лист проверок
  каталога, личного кабинета, корзины и заказов.
- Подготовил подробные тест-кейсы и оформил примеры баг-репортов по сохранённым API-результатам.
- Реализовал набор автотестов на Python с pytest: 17 API-случаев через Requests,
  16 UI-сценариев через Selenium и один сквозной smoke-сценарий покупки.
- Использовал Page Object Model, фикстуры, подготовку данных через API и проверки
  согласованности UI с серверными данными.
- Добавил HTML-отчётность и скриншоты при падениях UI; описал установку зависимостей,
  настройку локального окружения и команды запуска в README.

**Стек:** Python 3.12, pytest, Requests, Selenium WebDriver, pytest-html, uv, Git.

---

CI, полностью успешный UI-прогон и промышленный опыт этой формулировкой не заявляются.
Исторические результаты API отдельно описаны в [results.md](results.md).
Названия `API-01` / `UI-01` — внутренние ID учебных сценариев, а не количество
обнаруженных производственных дефектов.
